# Finder and Preview

Open Finder directly at the checkout’s `images/` folder. Bind Preview only after opening the workshop file. If Finder assigns a different default viewer, use the selected JPEG’s **Open With → Preview** action. If Preview switches documents, return to the existing workshop copy when its identity is clear. Ask for help if you cannot verify it.

1. **Duplicate first.** Press **⌘⇧S** in Preview and verify an unsaved duplicate is active. Dismiss its title popover with Escape if it blocks the image. The original has its own file URL.
2. **Crop and rotate.** Show Markup and zoom out until the whole image has a margin. Use **Rectangular Selection** and drag against the current visible edges. Try **⌘K** to crop. If the pixel dimensions are unchanged, check the selection and retry using **Tools → Crop**. Scope any menu read to the Crop item. The Inspector can confirm the new pixel dimensions. Close it before placing annotations. **⌘L** rotates left and **⌘R** rotates right.
3. **Add text.** In Markup choose **Text**, double-click the placeholder, and set the exact caption using the focused editor. Verify the actual text, then click away and drag it inside the specified corner. For contrast, pick a clear area or use Text Style. Keep the caption within the image.
4. **Add a requested mark.** For a clean arrow or outline, use **Shapes**, select **Line with Arrow**, **Rectangle**, or **Oval**, and drag the visible handles. Check **Border Color** because Preview may reuse a transparent stroke. Keep an outline’s fill transparent. For a short freehand stroke, use **Sketch** and drag once on the image. Preview may recognize it as a geometric shape. For a requested freehand mark choose the sketched version when its palette appears. Use the browser editor if Preview’s controls hide the mark or the palette cannot be inspected. [Apple’s Preview guide](https://support.apple.com/guide/preview/annotate-an-image-prvw1501/mac).
5. **Save.** Press **⌘S**. If that only commits the active annotation, observe the state before pressing it again. In a save sheet starting within the workshop, use **⌘⇧G** to navigate directly to this checkout’s `edited images` folder. Verify the destination, JPEG format, and new basename before saving. Cancel any Replace prompt. If the sheet cannot be observed, pause for the participant to save off screen. Verify the saved document’s URL or Finder result before opening another photo. Review new annotations before saving because Preview flattens them into the JPEG.

Use app-scoped controls and current window bounds. Avoid the clipboard on stage and avoid opening Preview’s Window, File, Signature, or Share menus.
